Context-Free Grammar (CFG) for Cis-QL (v3.0-dev, regulatory foundation)

Terminals (Tokens):

LOAD, USE, EXPORT, DEFINE, PROMOTERS, MODULE, OF, SEQUENCE, ANNOTATION, TRACK, MATRIX, STRING, AS, ID, SEMICOLON, FIND, MOTIF, COUNT, WITHIN, NUM,
FROM, WITH, GENE, PROMOTER, ENHANCER, EXON, INTRON, UTR, TSS, CDS, REGION, STRAND, POSITIVE, NEGATIVE,
CHR, EXTRACT, WHERE, INTERSECT, UNION, EXCEPT, OVERLAPS, NEAR, AND, OR, NOT, LPAREN, RPAREN, LBRACKET, RBRACKET,
LENGTH, SIMILARITY, GREATER, LESS, GREATER_EQ, LESS_EQ, ASSIGN, FLOAT, PERCENT, BP, KB, MB,
UPSTREAM, DOWNSTREAM, SCAN, THRESHOLD, PVALUE, QVALUE, BACKGROUND, UNIFORM, ANALYZE, GC_CONTENT, CPG_ISLANDS, WINDOW,
IF, THEN, ELSE, ENDIF, FOREACH, IN, DO, ENDFOR, COMMA, TO, FORMAT, BED, GFF3, TSV,
SPACING, ORDER, ORIENTATION, ANY, SAME, OPPOSITE, AS_WRITTEN, NARROWPEAK,
EVIDENCE, ACCESSIBILITY, BINDING, OTHER, ASSAY, SAMPLE.

Grammar Rules:

Program            -> StatementList
StatementList      -> Statement StatementList | λ

Statement          -> LoadStmt | UseStmt | ExportStmt | DefinePromotersStmt | DefineModuleStmt | FindStmt | ExtractStmt | SetOperationStmt | CountStmt | ScanStmt | AnalyzeStmt | IfStmt | ForeachStmt

LoadStmt           -> LOAD (SEQUENCE | ANNOTATION | MATRIX) STRING AS ID SEMICOLON
                    | LOAD TRACK STRING FORMAT (BED | NARROWPEAK)
                      EVIDENCE (ACCESSIBILITY | BINDING | OTHER)
                      (ASSAY STRING)? (SAMPLE STRING)? AS ID SEMICOLON
UseStmt            -> USE (SEQUENCE | ANNOTATION) ID SEMICOLON
ExportStmt         -> EXPORT ID TO STRING FORMAT (BED | GFF3 | TSV) SEMICOLON
DefinePromotersStmt -> DEFINE PROMOTERS OF (GENE | TSS | ID) FROM TSS
                       UPSTREAM (NUM | FLOAT) RequiredUnit
                       DOWNSTREAM (NUM | FLOAT) RequiredUnit AS ID SEMICOLON
DefineModuleStmt   -> DEFINE MODULE FROM ID WITH ID
                      SPACING (NUM | FLOAT) RequiredUnit TO
                              (NUM | FLOAT) RequiredUnit
                      ORDER (ANY | AS_WRITTEN)
                      ORIENTATION (ANY | SAME | OPPOSITE) AS ID SEMICOLON

AnalyzeStmt        -> ANALYZE (GC_CONTENT | CPG_ISLANDS) (WINDOW (NUM | FLOAT) Unit)? AliasOpt WhereClause SEMICOLON

FindStmt           -> FIND MOTIF STRING FindOpts AliasOpt WhereClause SEMICOLON
FindOpts           -> FindOpt FindOpts | λ
FindOpt            -> WITHIN (NUM | FLOAT) Unit Direction FROM EntityRef EntityName
                    | STRAND StrandType
                    | CHR STRING

ScanStmt           -> SCAN ID ScanOpts AliasOpt WhereClause SEMICOLON
ScanOpts           -> ScanOpt ScanOpts | λ
ScanOpt            -> IN EntityRef
                    | STRAND StrandType
                    | THRESHOLD (NUM | FLOAT) PERCENT
                    | (PVALUE | QVALUE) (LESS | LESS_EQ) Probability
                    | BACKGROUND (UNIFORM | FROM EntityRef)

SetOperationStmt   -> (INTERSECT | UNION) EntityRef AND EntityRef AliasOpt WhereClause SEMICOLON
                    | EXCEPT EntityRef FROM EntityRef AliasOpt WhereClause SEMICOLON
                    | OVERLAPS EntityRef WITH EntityRef AliasOpt WhereClause SEMICOLON
                    | NEAR EntityRef TO EntityRef WITHIN (NUM | FLOAT) RequiredUnit AliasOpt WhereClause SEMICOLON

CountStmt          -> COUNT EntityRef IN EntityRef AS ID WhereClause SEMICOLON

ExtractStmt        -> EXTRACT EntityRef AliasOpt WhereClause SEMICOLON

IfStmt             -> IF Condition THEN StatementList (ELSE StatementList)? ENDIF (SEMICOLON)?

ForeachStmt        -> FOREACH ID IN LBRACKET CollectionList RBRACKET DO StatementList ENDFOR (SEMICOLON)?
CollectionList     -> CollectionItem (COMMA CollectionItem)* | λ
CollectionItem     -> ID

WhereClause        -> WHERE Condition | λ

Condition          -> Term ConditionPrime
ConditionPrime     -> OR Term ConditionPrime | λ
Term               -> Factor TermPrime
TermPrime          -> AND Factor TermPrime | λ
Factor             -> NOT Factor | SimpleCondition | LPAREN Condition RPAREN

SimpleCondition    -> Property RelOp Value | SIMILARITY SimilarityRefOpt RelOp Value
Property           -> LENGTH | GC_CONTENT | COUNT | ID
SimilarityRefOpt   -> TO ID | λ
RelOp              -> GREATER | LESS | GREATER_EQ | LESS_EQ | ASSIGN
Value              -> (NUM | FLOAT) Unit | (NUM | FLOAT) PERCENT | NUM | FLOAT | STRING
Probability        -> NUM | FLOAT

Unit               -> BP | KB | MB | λ
RequiredUnit       -> BP | KB | MB
Direction          -> UPSTREAM | DOWNSTREAM
Entity             -> GENE | PROMOTER | ENHANCER | EXON | INTRON | UTR | TSS | CDS | REGION
EntityRef          -> Entity | ID
EntityName         -> STRING | λ
AliasOpt           -> AS ID | λ
StrandType         -> POSITIVE | NEGATIVE

Note on Execution Engine & Studio Integration:
1. Cis-QL automatically compiles degenerate IUPAC nucleotide codes (e.g. TATAWAW) into regex patterns.
2. If an `AliasOpt` (AS ID) is not provided, Cis-QL auto-generates descriptive track names (e.g., `Find_TATAAT_0`, `Scan_tbp_1`).
3. Execution outputs are formatted into `.cisql_results.json` for live visualization in Cis-QL Studio.
4. GFF features are loaded exactly as annotated. Cis-QL does not synthesize promoters or TSS records during import.
5. `DEFINE PROMOTERS` requires an active sequence, explicit upstream/downstream distances, and stranded source features. Generated intervals are oriented from the TSS and clamped to chromosome bounds.
6. `SCAN matrix IN regions` restricts a PWM scan to a biological entity or named region set. Each hit retains matrix identity, raw and relative scores, its source region, and the source-oriented relative start. Omitting `IN` preserves whole-genome scanning.
7. `BACKGROUND UNIFORM` selects an explicit uniform zero-order background. `BACKGROUND FROM source` estimates nucleotide frequencies from a sequence dataset or region set and adds a total pseudocount of 0.1. The effective policy is forward, reverse-complemented for negative-only scans, or symmetrized for two-strand scans. Omitting the option retains the recorded uniform legacy default.
8. Every retained PWM hit records a zero-order dynamic-programming p-value and a Benjamini-Hochberg q-value. The correction covers all valid position-strand tests in the complete `SCAN`, including windows below reporting thresholds; ambiguous windows are excluded.
9. `PVALUE <|<= probability` and `QVALUE <|<= probability` select statistically calibrated hits. Scientific notation is accepted. Only one statistical threshold is allowed per `SCAN`; if `THRESHOLD ... %` is also present, both criteria must pass. Without an explicit relative threshold, a statistical scan does not inherit the legacy 75% cutoff.
10. `OVERLAPS query WITH reference` is a directional interval semi-join: it retains each query interval once when any reference interval overlaps it. Query coordinates, sequence, and motif evidence remain unchanged, and every matching reference is retained as typed `overlapEvidence`, including its imported track evidence when present. `INTERSECT` remains the geometric operation that emits clipped overlap segments.
11. `NEAR query TO reference WITHIN distance` retains each query interval whose nearest same-chromosome reference has an interval gap less than or equal to the explicit limit. Overlap and adjacency have distance zero but are distinguished by recorded overlap evidence. The complete query and its motif evidence are preserved; the chosen reference, distance, limit, and overlap state are attached to JSON, GFF3, and TSV results. Equal-distance ties use deterministic reference ordering. Proximity is not interpreted as proof of regulation.
12. `COUNT query IN containers` emits every valid container interval, including those with zero hits, and records how many query intervals overlap it under half-open coordinates. `WHERE COUNT` can select containers by the resulting non-negative integer. This is descriptive aggregation, not a statistical enrichment test.
13. `DEFINE MODULE` pairs records on the same chromosome when their half-open interval gap falls inside the inclusive `SPACING` range. Overlap and adjacency both have spacing zero, while the observed order records overlap separately. `ORDER AS_WRITTEN` requires the first input record to have a lower reference start than the second; tied starts do not satisfy it. `ORDER ANY` accepts either direction. `ORIENTATION SAME` and `OPPOSITE` require both members to have `+` or `-` strands. Reusing one alias forms canonical unordered pairs, excluding self-pairs and duplicate mirror pairs. JSON and Studio retain nested member evidence; GFF3 and TSV expose the constraints, member identities, and core PWM statistics.
14. `LOAD TRACK ... FORMAT BED|NARROWPEAK EVIDENCE ACCESSIBILITY|BINDING|OTHER` imports zero-based, half-open regulatory intervals as a named region set. The required evidence class records the user's declared interpretation; optional `ASSAY` and `SAMPLE` strings preserve experimental context. narrowPeak score, signalValue, -log10(p), -log10(q), and summit offset are preserved as typed track evidence. When a FASTA is active, chromosome names and interval bounds are validated and interval sequence is attached. Imported tracks can be used by the interval, count, scan, and module operators without becoming the active GFF3 annotation.
