# Historical prototype comparisons

These Python scripts belong to the original compiler-demonstration suite. They
are retained as implementation history, but they no longer correspond to the
curated programs in `cql_examples/` and should not be presented as biological
workflows or current performance comparisons.

The previous line-of-code and speed claims were removed because the scripts did
not establish equivalent inputs, semantics, outputs, or correctness. Use
`benchmarks/` for reproducible engineering measurements and run `make validate`
before comparing Cis-QL with an independent implementation or external tool.
